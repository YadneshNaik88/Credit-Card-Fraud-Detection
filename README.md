# Credit-Card-Fraud-Detection
# 💳 Credit Card Fraud Detection using Machine Learning

## 📌 Overview

This project uses Machine Learning to detect fraudulent credit card transactions. Due to the highly imbalanced nature of the dataset, multiple evaluation metrics such as Precision, Recall, F1-score, and ROC-AUC were used instead of relying only on accuracy.

---

## 🎯 Objective

To build a classification model capable of identifying fraudulent transactions while minimizing false negatives.

---

## 📂 Dataset

- Credit Card Fraud Detection Dataset
- Features:
  - Time
  - V1–V28 (PCA transformed features)
  - Amount
  - Class (0 = Legitimate, 1 = Fraud)
